# 💍 Shaadi Nimantran Generator

A free wedding invitation card generator built with Python,
Streamlit and Pillow.

## Features

- Seven religion categories
- Hindi and English templates
- Four wedding card themes
- Bride and groom names
- Wedding date, time and venue
- Family names and additional message
- Invitation preview
- PNG image download
- No API key required

## Technologies

- Python
- Streamlit
- Pillow

## Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/shaadi-nimantran.git
cd shaadi-nimantran
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```

## Free Deployment

Deploy using Streamlit Community Cloud:

https://share.streamlit.io/

Select this repository and set the main file to `app.py`.

## Note

This project uses built-in invitation templates.
It does not require a paid API or API key.
